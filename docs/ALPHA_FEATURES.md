# Desktop α版の機能状態

最低限の機能を実装したアルファ版です。Web版との完全な同等機能、全モデルの動作、別PCでの動作を保証するものではありません。

## 利用可能な基礎機能

- Ollama / OpenRouterでのチャット、ストリーミング、停止、再生成 (接続・モデル・キーが必要)
- 履歴、検索、プロジェクト、手動メモリー、複数システムプロンプト
- テーマ、会話JSONの追加インポート・エクスポート
- 対応文書の読込、成果物出力 (容量・形式・レイアウトに制限あり)
- Python / JavaScript / TypeScriptの隔離実行 (OS操作・ネット通信・追加Pythonパッケージなし)
- 選択フォルダーの音楽、ローカル同期歌詞、無料LRCLIB / lyrics.ovhでの外部取得
- セットアップ/設定からの候補モデル取得、独立した取得ワーカー、進捗/停止/再試行
- Web検索、天気、URL読取 (インターネット接続が必要)
- 対応APIモデルでの画像生成・参照画像・数学写真認識 (モデルごとの品質検収は継続中)

## 開発中

- WindowsネイティブSTT/TTS、音声・キャラクター通話、声クローン
- 動画取得、字幕処理、音声分離
- 高度な調査、ジョブ、エージェントの完全復旧

## 今後追加・対応予定

- 全資産を含む完全バックアップ、OCR
- 署名付きインストーラー、配信式自動更新、更新配信先
- 別PCでの検証、将来のmacOS / Linux対応

設定の「Desktop AI接続」と初回セットアップに、現在のPCでの利用可否を表示します。「利用可能」は接続条件を満たすという判定であり、APIキーの残高や全モデルの生成品質を保証しません。

## 推奨ローカルモデル

RAM・空きメモリー・論理CPU数からQwen 3.5の軽量候補を保守的に提示します。GPUと実際の生成速度は未測定です。ダウンロード容量は実行時の必要メモリーとは異なり、長いコンテキストでは消費量が増えます。自動ダウンロードしません。

CPU/GPU名とドライバー、Windows、Ollamaのバージョン・接続時間、モデル保存先空き容量も確認します。GPUのVRAM/実割当や実速度を測るベンチマークではありません。モデル取得は候補選択・確認後だけ開始し、完全終了後も別プロセスで継続します。電源断・スリープ・Ollama停止は継続対象外です。

モデルのタグ・配布容量は[Ollama公式Qwen 3.5一覧](https://ollama.com/library/qwen3.5)を参照しています。推奨のRAMしきい値は本アプリの選定基準で、公式の最低動作要件ではありません。
