# ココロネAI for Desktop α版

Windows 11向けのAIアシスタントです（チャット・数学・AIコーディング・ミュージック）。開発者: **くなまお**。
問い合わせ: **kunamaokunamao052867@gmail.com**。

α版です。Web版とのすべての機能の同等、自動更新、多数のPCでの動作確認は完了していません。機能の状態は[ALPHA_FEATURES.md](ALPHA_FEATURES.md)、権限の説明は[PERMISSIONS.md](PERMISSIONS.md)を参照してください。

## 必要なもの

- Windows 11 x64
- Microsoft Edge WebView2 Runtime（Windows 11には標準で入っています。無い場合は起動時に案内します）
- ローカルAIを使う場合: [Ollama](https://ollama.com/download/windows)、または llama.cpp server / LM Studio / Jan などのOpenAI互換ローカルサーバーと対応モデル
- 外部AIを使う場合: 自分のAPIキー（OpenRouter・OpenAI・Anthropic・Google Gemini）またはChatGPTのアカウントと、インターネット接続（利用料金は別途発生します）

自己完結版（インストーラー・通常のZIP）には.NETを同梱しているため、.NETの別途インストールは不要です。「minimal」と付いたZIPだけは[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0)が必要です。Ollama・AIモデル・APIキー・Python・Node.jsは同梱しません。

## インストール

**インストーラー（推奨）**: `.msi` を開きます。管理者権限は不要で、`%LOCALAPPDATA%\Programs\KokoroneAI` にインストールし、スタートメニューに「ココロネAI」を追加します。新しい版の `.msi` を開くと上書き更新します。

**ZIP**: 展開したフォルダーの `KokoroneAI.exe` を開きます。EXEだけを移動せず、同じフォルダーのDLL・`web-ui` 等も保持してください。

### 「WindowsによってPCが保護されました」と表示された場合

このα版は無料の自己署名で署名しており、有償の証明書による署名ではありません。そのため初回はMicrosoft Defender SmartScreenの警告が表示されます。入手元が公式のGitHub Releasesであることを確認し、次の方法で改ざんされていないことを確かめてから、「詳細情報」→「実行」を選んでください。

1. **ハッシュ値**: PowerShellで `Get-FileHash <ファイル名> -Algorithm SHA256` を実行し、Releasesの `SHA256SUMS.txt` の値と一致することを確認します。
2. **署名**: ファイルのプロパティ →「デジタル署名」で、署名者が「くなまお (KokoroneAI self-signed)」、証明書の拇印が次の値であることを確認します。

   `E6B22D9F6CB71BA9BC815EBAFDD8E9B10A25CEDD`

自己署名の証明書をWindowsの「信頼されたルート証明機関」に追加する必要はありません。追加しないでください。

## 初回起動

1. 初回セットアップで言語・外観と接続先（Ollama / OpenRouter / 両方）を選びます。完了するまでチャットは開きません。
2. Ollamaの場合は導入済みのチャットモデルを選択します。モデルが無ければ、候補を選び容量を確認してからセットアップ内で取得できます。
3. OpenRouterの場合は[公式管理画面](https://openrouter.ai/keys)で取得した自分のAPIキーを設定します。
4. PC診断、推奨モデル、利用可能・開発中の機能を確認します。
5. 利用条件とデータの扱いを確認して開始します。

## ココロネ Coding（AIコーディング）

サイドバーの「コーディング」でフォルダーを開くと、AIがそのフォルダーの中でファイルの読み書き・検索・コマンド実行・ブラウザーでの動作確認を行います。

- 書き込み・削除・コマンドは、選んだモードに応じて確認します（確認しながら / 編集は自動 / 計画のみ / フルアクセス）。「フルアクセス」では、開いたフォルダーの中の操作が確認なしで行われます。
- 作業ごとに「この作業を元に戻す」ができます（再起動後も可）。それでも、大切なフォルダーはバックアップかGitでの管理をおすすめします。
- `.env` や鍵ファイルなど秘密情報らしいファイルは、読む前に毎回確認します。フォルダーの外のファイル・システム設定・PC全体に関わるコマンドは扱いません。
- 設定の「コーディング」で、AIチーム（相談・分担・レビューを任せてよいモデル）を選べます。ローカルのコードをクラウドのモデルへ送る前は確認します。
- AIが読んだファイルの内容やコマンドの出力は、選んだAIの接続先へ送られます。ローカルAIだけを使えばPCの外へは送りません。

## Web検索の設定

Web検索には3つの方法があります。設定の「ツール」→「Web検索エンジン」で選びます。

- **SearXNG（推奨・無料）**: 自分で運用する[SearXNG](https://docs.searxng.org/admin/installation.html)のURL（例: `http://localhost:8888/`）を設定します。SearXNGの `settings.yml` の `search.formats` に `json` を加えてください。設定すると検索語はそのSearXNGだけに送ります。
- **DuckDuckGo（任意・既定はオフ）**: SearXNGが無い場合に、設定で明示的に有効にしたときだけ使います。[DuckDuckGoの利用規約](https://duckduckgo.com/terms)を確認してください。
- **モデル内蔵検索（OpenRouter・従量課金）**: 対応モデルで選べます。

どれも設定していない場合、検索語は外部へ送らず、設定方法を案内します。URLの読み取りでサイトが応答しない場合は、Common Crawlの保存コピーを探します（取得日を表示します）。

## データ

保存先は `%LOCALAPPDATA%\LumaAI-Desktop` です（旧名称のまま維持しています）。Web版の保存領域とは別管理です。

APIキーはWindowsユーザー単位のDPAPIで保護します。会話DB自体は暗号化していません。設定ファイルが壊れた場合は、直前の正常な設定から自動で復旧し、壊れたファイルは `settings.json.corrupt-日時` として残します。

## 常駐と終了

既定では、ウィンドウを閉じても通知領域で動作を続けます（初回だけ通知でお知らせします）。完全に終了するには、通知領域のココロネAIアイコンを右クリックして「終了」を選びます。この動作は設定の「通知」で切り替えられます。

モデル取得は画面とは別の処理のため、アプリを完全終了しても続きます。停止はアプリを再度開き、セットアップ/設定の進捗から行えます。

## アンインストール

Windowsの「設定」→「アプリ」から「ココロネAI for Desktop」をアンインストールします。会話・設定・APIキー（`%LOCALAPPDATA%\LumaAI-Desktop`）とOllamaのモデルは削除しません。完全に消す場合は、アプリを終了してからそのフォルダーを手動で削除し、APIキーは各提供者の管理画面で失効させてください。
