# ココロネAI for Desktop α版

Windows 11向けのAIチャットアプリです。開発者: **くなまお**。
問い合わせ: **kunamaokunamao052867@gmail.com**。

最低限の機能のみを導入したアルファ版です。Web版との全機能同等、署名付きインストーラー、自動更新、別PCでの動作確認は完了していません。機能状態は[ALPHA_FEATURES.md](ALPHA_FEATURES.md)、権限の説明は[PERMISSIONS.md](PERMISSIONS.md)を参照してください。

## 最小パッケージの準備

Windows 11 x64用です。[.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (SDKではなくWindows Desktop Runtimeのx64) と[WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)が必要です。Ollama・モデル・APIキー・Python・Node.jsは同梱しません。キーや履歴も含みません。

## 初回起動

1. 配布フォルダーを展開し、`KokoroneAI.exe` を開きます。EXEだけを移動せず、同じフォルダーのDLL・`web-ui` 等も保持してください。
2. 別ウィンドウの初回セットアップで言語・外観と接続先（Ollama / OpenRouter / 両方）を選びます。外観は即時反映されます。完了するまでチャットは開きません。
3. Ollamaの場合は導入済みのチャットモデルを選択します。Ollama本体が未導入なら[公式](https://ollama.com/download/windows)から導入し起動します。モデルはセットアップで候補を選択し、容量の確認後に直接取得できます。導入済みでも「他のAIモデルをダウンロード」から追加できます。
4. OpenRouterの場合は[公式管理画面](https://openrouter.ai/keys)で取得した自分のAPIキーを設定します。利用料金はモデル・アカウントにより異なります。
5. PC診断、推奨モデル、利用可能・開発中・対応予定の機能を確認します。Ollama未導入・未起動・モデル未導入はそれぞれ案内します。既存の設定や履歴は消しません。
6. 利用条件とデータの扱いを確認し、開始します。セットアップだけで終了した場合、次回もセットアップから再開します。

基本的なチャットにNode.js、npm、Pythonは不要です。フレームワーク依存ビルドでは.NET 10 Desktop Runtimeが必要です。自己完結型ビルドには.NETを同梱します。いずれも[WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)が必要です。

## データ

通常の保存先は `%LOCALAPPDATA%\LumaAI-Desktop` です。Web版の保存領域とは別管理です。Web版の履歴やキーを勝手に読み込みません。

APIキーはWindowsユーザー単位のDPAPIで保護します。会話DB自体は暗号化していません。他のWindowsユーザーや別PCへ秘密情報ファイルをコピーしても、同じ方法では復号できません。

会話のJSONインポートは利用者の操作で実行します。既存データの上書きではなく追加復元です。APIキー、生成画像の実ファイル、すべての設定を移せる完全バックアップとは異なります。

## オフラインと追加ツール

ローカルOllamaモデルが導入され起動していれば、ネット未接続でもチャットできます。クラウドAI・Web検索・天気等の外部サービスは利用できません。Ollamaのクラウドモデルはオフライン対象外です。

設定の「Desktop AI接続」から接続を再設定できます。追加ツールの実行ファイルは各利用者が選択します。開発者のPCにある固定パスは不要です。

FFmpeg、yt-dlp、Python等を検出できることと、対応するDesktop機能が復旧・検証済みであることは別です。未接続の機能は使えると案内しません。巨大なAIモデルを無断でダウンロードすることもありません。

コード実行の隔離環境は同梱WebAssemblyを使います。PC上のPythonやNodeでAIのコードを直接実行しません。Pythonの追加科学計算パッケージ、OS操作、ネット通信は通常のPC上のPythonと同じには使えません。

## 常駐と終了

常駐設定が有効な場合、ウィンドウを閉じても通知領域で動作を続けます。終了するには通知領域のココロネAIメニューから終了を選びます。アンインストール時に会話を自動で消しません。

モデル取得は画面とは別の処理のため、完全終了後も継続します。停止はアプリを再度開き、セットアップ/設定の進捗から行えます。PC電源断・スリープ・Ollama停止では継続できません。Ollamaのモデル自体をアプリが勝手に削除することはありません。

音楽の歌詞はローカルLRC・TXT・埋め込みを優先し、無料LRCLIBを標準に外部取得します。lyrics.ovhまたはローカルのみへ切り替え可能です。外部取得で音声・ファイルパスを送信しません。
