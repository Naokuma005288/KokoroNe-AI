# v0.3.0 α → v0.5.0 α で変わったこと

v0.3.0 α（2026-10-13）から v0.5.0 α（2026-10-18）までの変更を、分野ごとにまとめた一覧です。
v0.4.0 として準備していたものも v0.5.0 に含まれています。各版の説明は [Releases](https://github.com/Naokuma005288/KokoroNe-AI/releases) にあります。

## ミュージック

| 項目 | v0.3.0 | v0.5.0 |
|---|---|---|
| ミュージック画面 | 一覧と小さな歌詞欄 | 作り直し。大きな見出しと「再生」「シャッフル」、番号と再生中の動きつきの曲一覧、大きなジャケットのアルバム・丸いアーティスト、右に再生中の曲と歌詞、下にプレイヤーバー |
| フルスクリーンプレイヤー | なし | 新規。左にジャケット、右に歌詞（歌詞が無い・隠したときはジャケットを中央） |
| 背景 | — | ぼかしたジャケット＋ジャケットの色のメッシュグラデーション。バスドラム・ベースに合わせて穏やかに動く（オフ可） |
| 歌詞の表示 | 行ごと | 大きな文字、今の行が明るく離れた行ほど薄い。今の行を中央に。最後に提供元・曲名などのクレジット |
| 流れる歌詞（左から右） | なし | 単語ごとの時刻がある歌詞は Apple Music 風になめらかに。オン/オフ可 |
| 流れる歌詞を AI で作る（α版） | なし | demucs で歌声を分け、Whisper と whisperx（wav2vec2）で1文字・1単語ごとに位置合わせ。行の時刻が無い歌詞・英語まじりにも対応。進捗表示、何度でも作り直し |
| 歌詞のタイミング | 手動の補正のみ | 曲ごとに自動で補正（はっきりしているときだけ） |
| 歌詞の取得 | 表記違いで見つからないことがあった | アーティスト名の文字の種類違い・アルバム違いでも見つかる。値が空の応答でのエラーを修正 |
| 英語の歌詞 | そのまま | 選んだ AI が意味を優先して日本語訳（光りながら表示、曲ごとに保存） |
| カラオケ | なし | 新規。ボーカル消去（demucs、無いときは簡易）・キー変更（±12半音）・速さ（0.5〜1.5倍） |
| 音の出力先 | Windows の既定のみ | スピーカー/ヘッドホンを選べる（X057） |
| ココロネプレイヤー | 音楽と動画を1画面 | ミュージックと別画面・別設定に分離。A–B リピート・再生速度、キューの並べ替え、URL取得とブラウザー、右側の AI コーナー |

## チャットと AI

| 項目 | v0.3.0 | v0.5.0 |
|---|---|---|
| 通常チャット | 1回の検索をしてから回答 | エージェントのように、AI が自分で検索・ページを読む・動画解析・道具を必要なだけ使い、途中経過を表示 |
| ツールの既定 | 何も選ばないと「ツールなし」 | 「自動ツール」（設定しなくても検索・道具を使う） |
| Web 検索 | 古い情報を最新として答えることがあった | 期間を指定して検索、新しい順、AI に今日の日付を伝える。長いページは質問に関係する部分を読む |
| 動画 | — | 動画リンクを AI が自動で解析（高速化） |
| 道具をチャットに | なし | AI が単位変換・QR・色・タイマーなどの道具を答えの下に出す |
| 依頼の順番待ち | なし | 生成中に Ctrl+Enter で次の依頼を予約（F009） |
| 料金 | 回答後のトークン数・有料警告 | 送信前の目安（F103）＋回答ごとの料金 |
| メモリー | 事実の自動保存 | 「決定：」（日付つき）と「訂正：」も自動で残す（F064・F108） |
| 思考の深さ | 〜最大 | Ultra（最大の上）と高速モード（対応モデル） |
| MCP・自動実行 | なし | MCP クライアント（外部ツール）と自動実行（毎日・曜日・間隔・1回・フォルダー） |

## 主な不具合の修正

| 内容 |
|---|
| キャラクターモードが使えなかった |
| 常駐バーで前の会話が残る、聞き取りが雑音で途切れる |
| 「自動再生を開始できませんでした」が消えない |
| 起動できないことがあった（チャットのエージェントの初期化順） |
| demucs が別の Python に入っていると見つからない |
| 歌詞取得で「…requires an element of type 'Number'…」のエラー |
| 前の曲の流れる歌詞が次の曲に重なる、カラオケの伴奏が別の曲に切り替わる |
