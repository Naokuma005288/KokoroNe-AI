# ココロネAI for Desktop プライバシーポリシー

版: desktop-2026-11-15.8 / 更新日: 2026年11月15日

## 1. 基本方針

ココロネAI for Desktop（以下「本アプリ」）は、開発者くなまおが提供する Windows アプリです。会話・設定・ライブラリなどのデータは原則としてこのPCの中に保存し、開発者のサーバーへ送ることはありません。開発者は利用者のアカウント・会話・APIキーを受け取りません。

外部へ送るのは、利用者が選んだAIや機能を使うときに、その機能に必要な最小限の内容だけです。送り先と内容は下の「4. 外部に送る場合」と機能ごとの詳細に記載します。

## 3. このPCに保存するもの

会話・メモリー・設定・音楽ライブラリ・生成物・ログは、利用者のデータフォルダー（通常は %LOCALAPPDATA% 配下、または --data-dir で指定した場所）に保存します。APIキーなどの秘密情報は Windows の DPAPI で暗号化して保存し、画面やログに表示しません。

## 4. 外部に送る場合（概要）

AIの接続先: クラウドAI（OpenRouter など利用者が設定した提供元）を選んだときは、会話・添付・道具の結果がその提供元へ送られ、提供元の規約とプライバシーポリシーが適用されます。ローカルAI（このPCのモデル）を選んだ場合は外部へ送りません。

検索・Web: Web検索・リンクの閲覧では検索語やURLが検索サービス・閲覧先へ送られ、閲覧先には IP アドレスなどが伝わります。

音楽: 曲名・アーティスト名での検索や再生では、曲名・アーティスト名を iTunes Search API・Deezer・YouTube などへ送ります。会話・APIキー・Cookie は送りません。

画像・動画・音声の生成: 利用者が設定した生成サービスへプロンプトや参照画像を送ります。料金が発生する場合があります。

スマートフォン接続: 初期状態は無効です。有効にすると同じネットワーク内の認証済み端末だけがこのPCへ接続できます。

追加の機能・モデルのダウンロード: 配布元から取得するときに、配布元へ IP アドレスなどが伝わります。

このほか、各機能で送る内容は「機能ごとの詳細」に記載します。

## 5. 送らないもの

広告、アクセス解析、追跡、会話・エラーログの開発者への自動送信は行いません。APIキー・パスワード・Cookie を AI や外部サービスの回答のために送ることはありません。利用者が自分で問い合わせや不具合報告を送った場合だけ、その内容を開発者が受け取ります。

## 6. 年齢

初回起動時に生まれた年をうかがい、このPCの中だけに保存します（外部へは送りません）。18歳以上向けの機能（無検閲AIなど）は、18歳以上であることの確認と個別の有効化をしたときだけ使えます。

## 7. 保存期間と削除

データは利用者が削除するまでこのPCに残ります。会話などはアプリ内で削除できます。アンインストールだけではデータは自動で削除されないため、完全に消すときはアプリを終了してからデータフォルダーと自分で作ったバックアップを削除してください。APIキーの失効は各提供者の管理画面で行ってください。外部サービスへ送った内容の保存期間は、各提供者のポリシーに従います。

## 8. このポリシーの変更

内容を変更したときは、版と更新日を改め、アプリの起動時に改めて同意をお願いします。

## 機能ごとの詳細

以下は機能ごとに、送る内容・送り先・保存する内容を詳しく記載したものです。上の概要と食い違う場合は、こちらの記載が具体的な扱いを示します。

### ワークモード（AIエージェント）（v1.1.0）

ワークモードは、頼んだ作業をAIが裏で最後まで進めるエージェントです。会話・道具の結果・添付ファイルから読み取った文字は、通常のチャットと同じく選んだAIへ送られます（クラウドAIの場合はその提供元へ）。画像を添付した場合、画像が分かるAIには最新のメッセージの画像も送ります。ワークのAIへの指示（設定 › ワーク）は、送るたびに会話と一緒に選んだAIへ送られます。中国の企業が開発したAI（DeepSeek・Qwen・Kimi・GLM・MiniMax など）は、安全上の理由でワークモードでは使いません。

AIが方法を調べるために、検索語やURLを検索サービス・閲覧先へ送ります。AIが書いたスクリプト（run_code・自作の道具）はこのPCで実行され、作業に必要な場合はインターネット上のサービスやAPIに接続することがあります。その送り先と内容は依頼によって変わります。個人情報（メールアドレス・電話番号・カード番号・パスワード・住所など）を外へ送る可能性がある操作、元に戻せない削除、支払い・購入、利用者の代わりの送信・投稿は、実行前に毎回確認します。

このPCに保存するもの: 作業フォルダー（ドキュメント\KokoroNe Work）に作ったファイル、データフォルダーの agent-tools（AIが作った道具のスクリプト）と requests（ワークの会話の内容・進み具合・結果と、添付したファイルの原本）。これらのファイル自体は外へは送りません（AIが作業のために読み取った内容は上のとおり選んだAIへ送られます）。会話は一覧から削除でき、削除すると添付の原本も消えます。自動では削除しません。

### 見張り役と行動の記録（v1.2.0）

見張り役は、ワークのAIがスクリプトを実行する・ファイルを変える・外へ送る前に、その操作が依頼の範囲かを確かめるAIです。見張り役には、利用者がその会話で書いた言葉、ワークのAIへの指示（設定 › ワーク）、確かめる操作の内容（スクリプトのコード・書き込む内容・送る先と内容など）を送ります。送り先は、設定 › ワーク › 見張り役で選んだAIです（「自動」ではその会話のAI。クラウドAIの場合はその提供元へ）。ワークのAIが読んだページや文書の中身は見張り役へ送りません。「規則だけ」を選ぶと、見張り役のAIには何も送りません。中国の企業が開発したAIは見張り役にも使いません。

行動の記録: ワークのAIの操作（日時・会話の名前・道具・対象・引数やスクリプトの内容・確認の結果・利用者の判断）を、データフォルダーの action-log に保存します。記録は外へ送らず、自動では削除しません。設定 › ワーク › 行動の記録からすべて消せます。

### ワークの道具・AIのブラウザー・計画役（v1.5.0）

AIのブラウザー: ワークのAIは、作業用の別のブラウザー（「AIが操作中」と表示される窓）でサイトを開き、読み、押し、入力し、素材や動画を保存できます。開いたサイトには、通常のブラウザーと同じくURL・IPアドレスなどが伝わります。このブラウザーのCookieやサインインは、データフォルダーの agent-browser-profile に、通常のブラウザーやココロネの画面とは分けて保存します。パスワード・カード番号・確認コードの欄にはAIは入力しません。購入・送信・投稿・削除に見えるボタンは押す前に確認します。ページの内容と、画像が分かるAIにはページの画像も、その会話のAIへ送ります（クラウドAIの場合はその提供元へ）。

ダウンロード: AIが保存したファイルや動画は作業フォルダーの Downloads に保存し、自動では実行・削除しません。プログラムやスクリプトの保存は確認します。動画の保存には外部実行環境（yt-dlp）を使います。配信元の規約と利用権利を確かめてください。

ローカルAIの設定: AIはこのPCの Ollama などの状態を確かめ、つなぐ・外す・モデルを取得することができます（外す・取得は確認します）。モデルの取得では、その配布元からダウンロードします。中国の企業が開発したモデルは取得しません。

コーディングモード: AIはコーディングモードに作業を頼めます。作業は元のフォルダーの写し（作業ブランチ）で行い、元のフォルダーは利用者が取り込むまで変わりません。

ココロネAIの設定: AIが変えられるのは見た目と使い勝手の一部（テーマ・文字の大きさ・言語など）だけで、権限・プライバシー・料金に関わる設定は変えられません。

計画役: 設定 › ワークで計画役のAIを選ぶと、依頼のたびに、依頼の文と使える道具の名前・短い説明をそのAIへ送り、段取りを作ってもらいます（クラウドAIの場合はその提供元へ）。中国の企業が開発したAIは使いません。料金の見積もりと上限は、このPCの中だけで計算します。

### Cloudflare Tunnel・Cloudflare Accessでのスマートフォン接続（v1.12.0）

Cloudflare Tunnelでのスマートフォン接続（v1.12.0、初期状態は無効）: 設定 › スマホから使う で「Cloudflare Tunnel」を選んだ場合だけ、利用者が自分のCloudflareアカウントで作ったトンネルのプログラム（cloudflared）をこのPCで起動し、スマートフォンとの通信（画面・会話・設定・許可したフォルダーのCodingの内容など、Tailscaleでの接続と同じもの）がCloudflare, Inc.のネットワークを通ります。通信はHTTPSで暗号化されますが、Cloudflareの規約とデータの扱いが適用されます。トンネルのトークンはWindowsの保護（DPAPI）をかけてこのPCにだけ保存し、画面やログには出しません。

Cloudflare Accessでの本人確認（v1.12.0）: 本人確認はCloudflare Access（利用者のZero Trustの設定、例えばメールアドレスへの確認コード）が行います。ココロネAIは、届いたすべての要求でAccessが付けた署名（Cf-Access-Jwt-Assertion）を、利用者のチームの公開鍵（チーム名.cloudflareaccess.com から取得し1時間保持します）とアプリケーションのAUDタグで確かめ、通っていないものは断ります。そのうえで、これまでどおりPCで登録した端末だけが使えます。設定画面の「外から確かめる」を押したときだけ、このPCから公開ホスト名へ確認の要求を1回送ります。チーム名・AUDタグ・公開ホスト名はこのPCの設定に保存します。

接続中の画面（v1.12.0）: スマートフォンで開いたときに出る接続中の画面は、すでにスマートフォンが受け取ったものだけで動き、外へ何も送りません。

### チャットでの作業・画像検索・スマートフォンのブラウザー（v1.11.0）

チャットでの作業（v1.11.0）: 通常チャット（キャラクターとの会話も）で作業を頼むと、ワークと同じ道具（作業フォルダーのファイル・書類づくり・AIのブラウザー・PCの道具など）を使います。そのときAIへ送るもの・確認・自分で決める規則・見張り役・行動の記録は、ワークモード（v1.1.0〜）の項と同じです。「ワークに移って」「裏で進めといて」でワークに移るときは、それまでの会話をこのPCの中でワークのスレッドに写します。

画像検索（v1.11.0）: 画像を探すとき、検索の言葉を Wikipedia（日本語・英語）、Wikimedia Commons、Openverse（18歳未満の設定では使いません）、設定したSearXNGへ送ります。AIが見つけたページの代表画像を探すときは、そのページ（公開のアドレスだけ）を読みに行きます。画像はこれまでどおりココロネAIを通して表示します。

チャットで事実を調べる道具（v1.11.0）: 天気は地名を Open-Meteo へ、為替レートは通貨の記号を Frankfurter（欧州中央銀行の参考レート）へ、百科事典は調べる言葉を Wikipedia へ、場所と距離は地名を Open-Meteo の地名検索へ送ります。送るのは調べる言葉だけで、会話やアカウントの情報は送りません。

スマートフォンからのAIのブラウザー（v1.11.0）: スマートフォンから頼んだ作業でもAIのブラウザー（このPCで動きます）を使います。スマートフォンで「AIのブラウザーを見る」を押したときは、表示中のページの画像とタブの一覧（題名とURL）を、つながっているそのスマートフォンへだけ送ります（チャットかワークの許可があるときだけ）。

AIのカーソル（v1.11.0）: AIが画面やAIのブラウザーを操作するときに出すカーソルは、このPCの画面に表示するだけで、画面の撮影には写らず、どこへも送りません。

### チーム・見せて覚えさせる・見守り・スペース（v1.10.0）

エージェントのチーム（v1.10.0）: エージェントに役割を書くと、ワークのAIは仕事の一部をほかのエージェントに頼みます。頼むときは、その仕事に必要な内容（依頼の文・集めた情報）と、そのエージェントの役割と話し方を、その会話で選んでいるAI（クラウドAIの場合はその提供元へ）へ送ります。頼まれたエージェントの作業も、ふだんのワークと同じ確認・規則・Privacy Zones の決まりで行います。

見せて覚えさせる（v1.10.0、利用者が始めたときだけ）: 記録中は、前に出たウィンドウのアプリ名と題名、押したボタンや欄の名前、欄に入った文字、Enter などのキーをこのPCのメモリーに記録します。キー入力そのもの、パスワード欄、サインイン・管理者の確認の画面、Privacy Zones のアプリ、ココロネAI自身は記録せず、鍵やカード番号のような文字は伏せます。利用者が確かめて「スキルにする」を押したときだけ、その手順の文を選んでいるAI（クラウドAIの場合はその提供元へ）へ送り、できたスキルはデータフォルダーの skills に保存します。

出来事のきっかけと見守り（v1.10.0、利用者が作ったときだけ）: 「出来事」の自動実行のために、ココロネAIは1分ごとに電池の残り・Cドライブの空き・動いているプログラムの名前をこのPCの中で調べます。予定やメールのきっかけでは、接続済みのカレンダー・メールのコネクターで今日の予定と未読メールの一覧を読み（読むだけです）、その内容はこのPCの中で比べるだけで、きっかけが起きたときに初めて、その自動実行の依頼と一緒に選んだAIへ送ります。「見守り」は書き込み・送信の道具を使わずに調べ、あなたの目標と記憶を参考にAIへ送ります。毎朝のまとめはこのPCの中で作ります。

スペースと規則（v1.10.0）: スペース（サイドバーに固定したアプリ）の状態とAIが届けたデータ（spaces.json）、自分で決める規則（work-rules.json）、エージェントの役割と使えない操作は、データフォルダーにだけ保存します。規則の文はワークの見張り役とAIへの指示に含めて送ります。

AIのブラウザーのタブとログインの交代（v1.10.0）: AIのブラウザーで複数のタブを開いたとき、AIはタブの一覧（題名とURL）と、読むと決めたタブの内容をその会話のAIへ送ります。確認コードや画像認証の場面では利用者に交代し、そのあいだの入力はAIへ送りません。作業のやり方の記憶（「やり方：」）は、ほかの記憶と同じく会話のAIへの指示に含めて送ります。

### デスクトップの操作・PCのブラウザー・LINE・スマートフォンからのワーク・制限の緩い画像生成（v1.9.0）

デスクトップの操作（v1.9.0）: AIに見せる・操作させる範囲は、1つのウィンドウか「画面1」などの画面全体です。画面全体を見る・操作するときは、その作業で最初に毎回確認します。画面全体の画像では、ココロネAI自身の窓を隠し、パスワード・サインイン・管理者の確認の窓とPrivacy Zonesに入れたアプリの範囲を黒く塗ってから、その会話のAI（クラウドAIの場合はその提供元へ）へ送ります。拡大や目盛り（座標の線）を付けた画像も同じです。マウスのボタン・長押し・ドラッグ・スクロール・キーの組み合わせなどの入力は、押す場所がココロネAI自身・保護された窓・Privacy Zonesの上なら断ります。画像はこのPCに保存しません。

PCのブラウザー（v1.9.0）: 設定 › AIが使うブラウザーで「PCのブラウザー」または「自動」を選ぶと、ワークのAIはURLをこのPCのブラウザー（Chrome・Edgeなど、普段のサインインのまま）で開き、デスクトップの操作でそのウィンドウを読み・操作できます（開く前に確認します）。この場合、ページの画像と内容はデスクトップの操作と同じ扱いでAIへ送られ、サイトには普段のブラウザーのCookieやサインインが使われます。「ココロネのブラウザー」を選ぶと、PCのブラウザーは使いません。

LINEとの連携（v1.9.0、初期状態はオフ）: 設定 › ツールボックス › コネクターでLINEを接続すると、利用者が自分で作ったLINE公式アカウント（Messaging API）のトークンと利用者のユーザーIDを、Windowsの資格情報として保存します。ワークの依頼が確認待ち・完了・失敗になると、その知らせ（会話の名前と短い説明。LINEからの依頼では答えの本文）をLINE（LINEヤフー株式会社）へ送り、利用者自身のLINEに届けます。「送信・依頼も可」にしてチャネルシークレットを設定した場合は、このPCで受付（127.0.0.1:43822）を開き、LINEから届いた利用者本人のメッセージ（署名を確かめ、本人以外は無視します）をワークの依頼として受け取ります。受付をインターネットから届くようにする作業（Cloudflare Tunnelなど）は利用者が行います。「送信・依頼も可」では、AIが作業の結果などを利用者本人のLINEへ送ることもあります（道具 line_send）。送り先は利用者本人だけで、ほかの人には送りません。

スマートフォンからのワーク（v1.9.0）: 端末ごとに「ワークの依頼」を許可した場合だけ、スマートフォンからワークの会話を作る・送る・止める・見ることができます。スマートフォンやLINEからの依頼では、AIはPCの画面（デスクトップ）を見ず・操作せず、確認が必要な操作はPCのココロネで答えるまで待ちます。

制限の緩い画像生成（v1.9.0、初期状態はオフ・18歳以上だけ）: オンにすると、画像を作る依頼に成人向けの決まり（登場人物はすべて成人の架空の人物であること）を加えて画像AIへ送ります。未成年を思わせる性的な依頼は、どの設定でも画像AIへ送らずに断ります。この設定はこのPCにだけ保存します。

PCの道具と確認のしかた（v1.9.0）: ワークとコーディングのAIは、PCの状態（CPU・メモリー・ディスク・バッテリー・ネットワーク・動いているプログラムの名前と窓の題名）、スタートメニューのアプリの一覧、利用者のフォルダー（デスクトップ・ドキュメント・ダウンロード・ピクチャ・ミュージック・ビデオ・OneDrive）のファイル名・大きさ・日付、クリップボードの文字（読むとき）を調べ、その結果をその会話のAI（クラウドAIの場合はその提供元へ）へ送ります。Privacy Zones に入れたアプリ・フォルダー・文字と、鍵やパスワードが入っていそうなファイルは、調べた結果から除きます。アプリの起動・終了、ファイルを開く、音量・再生の操作、通知はこのPCの中だけで行い、外へは送りません。確認のしかた（確認しながら・自動承認・フルアクセス）は、データフォルダーではなくこのPCのココロネの設定に保存し、外へは送りません。

PCの道具の追加（v1.9.0）: ワークとコーディングのAIは、さらに、フォルダーの容量・大きいファイル・同じ内容のファイル、インストール済みのソフトとWindowsと一緒に起動するもの、Windowsのログのエラー、ディスクの健康状態、バッテリーの劣化、ネットワークの設定（IPアドレス・Wi-Fiの名前と強さ）、プリンターの名前、エクスプローラーで開いているフォルダーと選んでいるファイル、最近使ったファイルを調べ、その結果をその会話のAIへ送ります（Privacy Zones と鍵らしいファイルは除きます）。ping・名前の確認（DNS）・ポートの確認では、AIが指定した相手へこのPCから通信します。ソフトの検索・インストール・更新（winget）では、Microsoftのwingetの配布元とソフトの提供元からダウンロードします（インストールでは提供元の利用条件に同意したことになります）。ファイルの整理・印刷・読み上げ・電源・画面の明るさ・画面の保存（パスワードの窓とPrivacy Zonesは黒く塗ります）・計算や暦の道具は、このPCの中だけで行います。

### ブラウザーからのログイン情報の取り込み（v1.8.0）

ブラウザーからの取り込み（任意・初期状態では行いません）: 設定 › ワーク › ログイン情報の「ブラウザーから取得する」を押し、確認画面で同意した場合だけ行います。ココロネAIは Chrome・Edge のパスワード保存場所（ブラウザーのプロファイルや暗号化された保存データ）を直接読むことはありません。利用者自身がブラウザーの設定画面で「パスワードをエクスポート」を行い（ブラウザーがWindowsのパスワード・PIN等での本人確認を求めます）、書き出されたCSVファイルをココロネAIが読み込みます。

読み込む内容と保存先: CSVのうち、サイトのアドレス・ユーザー名・パスワードだけを使います（メモ欄などは使いません）。アプリ用の行・httpsでないサイト（このPCのテスト用サイトを除く）・パスワードのない行・重なりは除きます。利用者が一覧で選んだものだけを保存し、パスワードはWindowsの資格情報マネージャーに、サイト・ユーザー名・サインインのページはデータフォルダーの site-logins.json に保存します。すでに保存しているアカウントはパスワードを新しいものに置き換えます。一覧の画面にはサイトとユーザー名だけを表示し、パスワードは表示しません。

送らないもの: 取り込みはこのPCの中だけで行い、CSVの内容・パスワード・サイトの一覧を、開発者・AI（クラウドAIを含む）・見張り役・行動の記録・ほかの端末（スマートフォンからの接続を含む。この機能はPCの画面でだけ使えます）へ送りません。読み込んだ内容は確認画面のあいだだけメモリーに置き、保存・取り消し・15分の経過で消します。

書き出したファイルの扱い: ブラウザーが書き出すCSVにはパスワードが暗号化されずに書かれています。初期状態では、保存したあとココロネAIがファイルをゼロで上書きしてから削除します（ごみ箱には入れません。SSDの仕組みやバックアップ・同期ソフトにより、完全な消去を保証できない場合があります）。削除しない設定にした場合や削除に失敗した場合は、その旨を表示しますので、利用者ご自身で削除し、ごみ箱を空にしてください。ファイルを探すときは「ダウンロード」フォルダーの直近2時間のCSVの1行目（列名）だけを確かめます。

取り込んだログイン情報の使い方は上の「ログイン情報」と同じです。不要になったものは設定から個別に消せます（Windowsに保存したパスワードも消えます）。

ログイン情報: 設定 › ワーク › ログイン情報で保存したサイト・ユーザー名・パスワードのうち、パスワードはWindowsの資格情報マネージャー（このPCのこのユーザーだけが読める場所）に、サイトとユーザー名はデータフォルダーの site-logins.json に保存します。ワークのAIがサインインを頼んだとき、ココロネAIがそのサイトのhttpsのページ（同じサイトかその下のアドレスだけ）のサインイン欄に入れ、そのサイトへ送られます。パスワードはAI（クラウドAIを含む）・見張り役・行動の記録・画面には渡さず、ユーザー名とサイト名だけがその会話のAIに伝わります。設定から消すと、Windowsに保存したパスワードも消えます。

エージェントの交代: 会話の途中でエージェントを切り替えると、前の答えを書いたエージェントの名前を、新しいエージェントの名前・話し方と一緒にその会話のAIへ送ります。どのエージェントが答えを書いたかは、データフォルダーのワークの会話に保存します。

### 自分だけのエージェント・通話・目標（v1.6.0）

名前と話し方: 設定 › ワーク › 自分だけのエージェントで決めた名前・話し方（自分で書いた文を含む）・あなたの呼び名を、ワークのメッセージと一緒にその会話のAIへ送ります（クラウドAIの場合はその提供元へ）。「次にできること」をオンにしているときは、その書き方の指示も添えます。設定はこのPCに保存します。選んだ画像はこのPCの中で小さくして設定に保存し、AIにもほかのどこにも送りません。

音声の再生: 答えの中の音声ファイル（AIが作った・保存したもの）は、「再生」を押したときだけこのPCで読み込み、会話の中で再生します。

目標: AIが作った目標と手順・進み具合は、データフォルダーの goals.json に保存し、外へは送りません（ワークのAIが道具で目標を確かめたとき、その内容はその会話のAIへ送られます）。道具 › 目標から消せます。

### コネクター（v1.4.0）

コネクターは、利用者がつないだアプリ（メール・カレンダー・GitHub・Notion・このPCの Outlook・ほかのPC（SSH）・MCPサーバー）を、チャットとワークのAIが使えるようにする機能です。つながっていない初期状態では何も送りません。

送る先と内容: AIが道具を使うと、このPCから利用者のアカウントのサービスへ直接つながります（メールは利用者が設定した受信・送信サーバー、GitHub は api.github.com、Notion は api.notion.com、カレンダーは利用者が入力した iCal アドレス、SSH は利用者が登録したPC）。サービスから届いた内容（メール・予定・Issue・ページ・コマンドの結果など）は、その会話のAIへ渡します（クラウドAIの場合はその提供元へ送信されます）。ワークでは、見張り役にも操作の内容（宛先・本文など）を送ります。

パスワード・トークン・カレンダーのアドレスはこのPCに暗号化（DPAPI）して保存し、AIにも見張り役にも渡しません。Outlook（このPC）と SSH は、パスワードを保存しません（Outlook 自身のサインインと、SSH の鍵を使います）。

どこまでしてよいか（オフ・読むだけ・下書きまで・送信も可）はアプリごとに利用者が選び、送信・投稿の前には毎回確認します。つないだ直後は「読むだけ」です。メールは読んでも既読にしません。下書き（GitHub の Issue・予定の招待ファイル）は、このPCのデータフォルダーの connector-drafts に保存します。接続を切ると、保存したパスワード・トークンも消えます。

### 全般（AI・検索・生成など）

AIがPCスペック確認ツールを使った場合、CPU・GPU・OS・コア数・RAM容量と空き容量を選択AIへ送ります。クラウドAIの場合は提供元へ送信されます。ファイル内容・ユーザー名・機器のシリアル番号は取得しません。画像の生成枚数はモデルの公表上限まで選択でき、枚数に応じて生成料金が増える場合があります。

通常チャットのDeep Researchでは、コーディングと共通のAIチーム設定で選ばれたメンバーに公開の検索根拠を渡し、確認結果を最終回答に利用します。ローカルは逐次処理します。追加クラウドの承認が必要な場合、または費用上限を保証できない場合は追加呼び出しを省略します。通常チャットの画像生成ツールはAIが作成した生成プロンプトと参照情報を設定済み画像サービスへ送り、従来の画像利用権限と承認に従います。能力を質問するだけでは生成を依頼した扱いにしません。

回答のWebリンクを押すと、PCではコーディングと共通の分離ブラウザーを使い、スマホではPCが公開ページを読み取って本文を認証済み接続で返します。閲覧先にはURLとIPアドレス等が伝わりますが、会話全文やAPIキーは渡しません。スマホの読み取り表示はサイトの対話操作やログインには対応せず、必要なら通常のブラウザーで開きます。

動画リンクは「取得して再生」を押したときだけ、設定済みの外部実行環境を使ってPCのmedia-downloadsに取得します。取得済み動画はチャット権限を持つ認証済み端末へ配信します。小窓の移動自体では外部通信しません。取得物は自動削除しません。配信元の規約・利用権利と、以下の外部実行環境の制限を確認してください。

スマホのCoding自動編集・フルアクセスは、Coding閲覧/実行権限とは別のPC側の明示許可と、作業開始時のスマホ側の確認が必要です。許可された作業フォルダーで編集・削除・コマンドを毎回の確認なしに実行し、コマンドや選択AIに応じた外部通信が発生することがあります。安全モード・Privacy ZonesとPCでのみ承認できる危険操作の保護は維持します。端末が自分の権限や許可フォルダーを増やすことはできず、既存端末には自動許可しません。

CodingのコマンドはPC上で実行し、隔離されたサンドボックスではありません。開始フォルダーの外のファイル・ネットワークにも影響する可能性があります。スマホのフルアクセスも同様です。

スマホのMusic共有は端末ごとの別権限で、既定はオフです。PCで許可した端末にだけ、Musicに登録済みの曲一覧・音声・ジャケット・歌詞と、連携済みSpotifyの音楽情報を送ります。認証済みHTTPSで再生・シークでき、任意のPCファイルパスは指定できません。歌詞翻訳・同期・カラオケの処理はPCで実行します。AI処理は選択モデルの通信条件に従います。Windowsのフォルダー選択・外部アプリ起動・キー管理はスマホに開放しません。

Tailscaleでの接続は廃止します（v1.13.0）。v1.13.0からは、TailscaleのCLIでの確認やServeの設定は行わず、新しくTailscaleで接続することはできません。それより前に設定したTailscale Serveの接続は、Cloudflare Tunnelに切り替えるまでのあいだ、そのまま使えます。

### スマートフォンからこのPCを使う（初期状態は無効）

PCの設定で有効にした場合だけ、127.0.0.1上に接続サービスを起動します。利用者が管理するCloudflare Tunnel（Cloudflare Accessで本人確認したものだけを受け付けます）、またはv1.13.0より前に設定したTailscale ServeのHTTPS接続を通じ、PCで登録を承認した端末へ画面・会話・設定・許可済みフォルダーのCoding内容を送ります。それぞれのアカウント・接続条件・データの扱いは各社の条件に従います。HTTPS証明書のホスト名は証明書の公開台帳に記録されます。開発者の中継サーバーへ会話を送りません。

APIキー本体やPCの認証用ファイルはスマホへ送りません。通常チャット・数学はPCと同じAI接続・検索設定を利用します。会話や添付をクラウドAIへ送る条件は従来と同じです。スマホのマイク・カメラ・現在地は、その端末のブラウザー権限に従います。CodingはPCで明示的に許可した作業フォルダーに限定し、安全モードを必須にします。PCの画面・クリップボード・範囲外操作等の承認、接続先・APIキー・実行環境・端末権限の管理はPCに残します。チャット閲覧権限を許可した端末からは共通のチャット・メモリーを読めるため、本人が管理する信頼できる端末だけを登録してください。

通信切断だけではPCのAI処理は終了しません。再接続時に一定量の受信履歴を再送し、最終回答はPCへ保存します。PCの終了・スリープ・再起動では継続を保証しません。ブラウザーの画面保持中に登録を解除しても、すでに閲覧・コピー・ダウンロードされた内容までは消せません。

### 道具のAI・自動実行・外部ツール（MCP）

- **道具の「AIに頼む」**（要約・校正・翻訳・ToDoの取り出し・配色など）は、押したときだけ、その道具に入っている文章をチャットで選んでいるAIの接続先へ送ります。
- **自動実行**は、利用者が作った頼みごとを決めた時刻に、選んだモデルへ送ります（ツールを許可した場合はWeb検索・ページの読み取り・MCPのツールも使います）。アプリが起動している間だけ動きます。結果はデータフォルダー（automations.json）に直近20回分を保存します。フォルダーを指定したコーディングの自動実行では、そのフォルダーのコピー（作業用分岐）で、コーディングモードと同じようにAIが読んだファイルの内容やコマンドの出力を選んだモデルへ送ります（確認が必要な操作は行いません）。クラウドのAIでは、実行のたびに送信と料金が発生します。
- **外部ツール（MCP）**は、利用者が追加してオンにしたサーバーだけをこのPCのプログラムとして起動し、AIが選んだツールの引数をそのサーバーへ渡します。サーバーが外部と通信するかどうかは、そのサーバー次第です。設定はデータフォルダー（mcp.json）に保存します。アプリのキー類（名前にKEY・TOKEN等を含む環境変数）は、サーバーごとに利用者が指定したもの以外は渡しません。
- **PCの様子**: ネットワークの通信量（合計の速さだけ）と、マイクを使っているアプリ（Windowsのプライバシー設定の記録を読むだけ）を表示します。どちらも保存・送信しません。
- **作業時間**（既定はオフ）: オンの間だけ、前面にあるアプリの名前を10秒ごとに記録し、日ごとの合計をデータフォルダー（worktime.json）に14日分だけ保存します。窓の題名・画面・入力した文字は記録しません。AIで振り返るときだけ、アプリ名と時間をAIへ送ります。
- **フォルダーの見張り（自動実行）**: 利用者が指定したフォルダーの変更（ファイル名と種類）を見て、自動実行の頼みごとと一緒に選んだモデルへ送ります。

- **クリップボード履歴**は「今のを追加」を押したときだけクリップボードを読み、PC内に保存します。

### 画面の撮影とメモリーの自動保存

画面について質問したとき（Mini Chat の撮影ボタンを含む）、AIが必要と判断すると、その時点の画面を撮影して答えに使います。ココロネAI自身のウィンドウは写りません。撮影した画像はその回答のためだけに使い、ファイルとしては保存しません（会話に添付として残る場合を除きます）。ローカルAIを使うときは画像も文字の読み取り（Windows標準のOCR）もこのPCの中だけで処理します。外部のAI（OpenRouter・直接接続・ChatGPT連携）を使うときは、設定で「クラウドのAIにも画面を送る」を許可した場合だけ、画像と読み取った文字（画像を読めないAIには文字だけ）をそのAIの提供者へ送信します（既定はオフ）。Mini Chat では「毎回、今の画面を添えて送る」（既定はオン）により、送るたびにその時点の画面（ココロネAI自身のウィンドウを除き、Privacy Zone のアプリは黒塗り）と読み取った文字を添えます。AIは質問に関係するときだけ使います。外部のAIへは、上の「クラウドのAIにも画面を送る」を許可した場合だけ送信します。この機能は設定の「Mini Chat」でオフにできます。

チャットでWeb検索が使えるとき、AIは答えに画像を入れるために画像検索をすることがあります（「画像を検索中」と表示します）。SearXNGを設定している場合はその画像検索を、設定していない場合は Wikimedia Commons の検索API へ検索語を送ります。答えに入った画像は、アプリが元のサーバーから取得して表示します（公開されたアドレスからのみ。画像のサーバーには、このPCのIPアドレスなど通常の接続の情報が届きます）。取得した画像はこのPCのデータフォルダー（web-images）に7日間保存し、その後自動で削除します。無検閲AIでも、Web検索・画像検索・天気・動画解析・歌詞・再生中の曲などのふだんのツールを使えます（画像生成・画面の読み取り・Deep Research・音声解析・PCの操作は使いません）。

### 18歳以上の利用者と無検閲AI

アカウントで18歳以上として登録している場合、AIへの指示に「成人向けの話題にもある程度まで率直に応じてよい」旨を加えます（未成年が関わる性的な内容、実在の人物の性的な描写や中傷、武器・薬物の製造や他人を傷つける手順、自傷の方法は扱わないよう、あわせて指示します）。無検閲AI（OpenRouter の、ふだんの制限をゆるめたモデル。モデル一覧に「無検閲・18歳以上」と表示）は、18歳以上として登録している場合に、最初に同意したときだけチャットで使えます。無検閲AIへは、ふだんのチャットと同じく、設定したシステムプロンプト・キャラクターや口調・言語の設定・記憶（メモリー）と、添付した画像を、OpenRouter を通じてそのモデルの提供者へ送ります（無検閲AIとの会話から新しい記憶は作りません）。無検閲AIを使った会話では、あなたの質問とAIの答え（使ったモデル名・会話の識別子・日時とともに）を、使った日から30日間、このPCのデータフォルダー（retention フォルダー）に保存します。この記録は通常の会話履歴とは別に保存され、一時チャットでも保存されます。保存期間中は、その会話をアプリから削除できません（「すべて削除」でも残ります）。30日を過ぎた記録は、アプリの起動時に自動で削除します。この記録を外部へ送ることはありません（会話の内容は、通常どおり選んだAIの提供者へ送信されます）。

### 曲名からの音楽再生

曲名で探して再生する機能（musicSearch / musicStream）を使ったときだけ、入力した検索語を iTunes Search API（Apple）と Deezer の検索APIへ送り、見つかった曲の「アーティスト名 曲名」を yt-dlp で YouTube の検索に使います。再生する曲を選ぶと、その動画の音声を yt-dlp と ffmpeg で取得し（「映像も取得」を選んだときは音のない480p以下の映像も）、このPCの ~/.cache/agent-music に保存します（次からはそれを使います）。Musicのフルスクリーンで「映像を探す」を押したときだけ、その曲の「アーティスト名 曲名」を yt-dlp で YouTube の検索に使い、見つかった映像（音なし・480p以下）を取得して、アプリのデータフォルダー（music の backdrops）に背景として保存します。チャットのAIが曲の情報（発売日・収録アルバム・ジャンルなど）を調べると判断したときは、AIが作った検索語（曲名・アーティスト名）を同じく iTunes Search API と Deezer へ送ります（ライブラリの検索はPC内だけで行います）。Musicで「アーティストを登録」したときは、そのアーティスト名を Deezer と iTunes Search API へ送って、曲名・アルバム・発売日とアーティストの写真を取得し、アプリのデータフォルダー（music-artists.json）に保存します（登録したアーティストは1日1回、新しい曲を同じように確認します）。音声はまだ取得せず、ライブラリにない曲を再生したときだけ、上と同じく「アーティスト名 曲名」を yt-dlp で YouTube の検索に使って取得します。（11-12b）Musicの検索欄は、設定「検索でオンラインの曲・アーティストも探す」がオン（初期値）のとき、入力した言葉を iTunes Search API と Deezer へ送り、オンラインの曲とアーティストを一緒に表示します。曲の上にカーソルを置いたとき（取得の確認に同意済みの場合）は、再生を早めるためにその曲の「アーティスト名 曲名」を先に yt-dlp で YouTube の検索に使います。Musicのホームのおすすめは、登録したアーティストを元に Deezer の「似たアーティスト」と人気曲・アルバムを取得します。設定「ライブラリのアーティストもおすすめに使う」をオンにしたときだけ、ライブラリで曲数の多いアーティスト名（最大5人）も Deezer へ送ります。（11-12c）同じ設定がオンのとき、チャットのAIの回答が音楽の話題で「」『』に入れた曲名を挙げると、その曲名だけを iTunes Search API と Deezer へ送って実在する曲かを確かめ、曲カード（再生ボタン付き）を表示します。「似た曲を続けて再生」では、再生中の曲のアーティスト名を Deezer へ送って似たアーティストの人気曲を取得し、選んだ曲を上と同じく取得して再生します（ライブラリには追加せず、次の曲に移ったら削除します）。会話・APIキー・Cookie は送りません。

### Minecraft で一緒に遊ぶ

設定の「接続 › Minecraft」で「KokoroNe と一緒に遊ぶ」をオンにしたとき（既定はオフ）だけ、KokoroNe の mod（利用者がボタンを押したときに Minecraft の mods フォルダーへコピーします）とこのPCの中（127.0.0.1）で通信します。mod が作る接続用の合言葉（token）は、Minecraft の config フォルダーの kokorone-ai.json にあり、このアプリが読み取ります。ゲームの中で KokoroNe に話しかけたとき（ほかに人がいないワールドでは、すべてのチャット）や、倒れた・夜になったなどの出来事のとき、そのチャットと発言したプレイヤー名、KokoroNe の様子（位置・体力・持ち物・周りのプレイヤー名と位置・生き物・目立つブロック）を、設定で選んだAIへ送ります（外部のAIなら、その提供者へ送信されます）。同じワールドのほかのプレイヤーの発言も、KokoroNe に話しかけたものは送られます。AIが「覚えておく」とした場所などのメモは、このPCのデータフォルダー（minecraft\notes.json）に保存し、外部へは送りません（次の会話でAIへ渡す場合を除きます）。mod を外すか、設定をオフにすると通信しません。

### マイク・位置・ファイル

マイク、カメラ、位置情報は該当機能を利用するときに使用し、Windowsのプライバシー設定に従います。音声の外部処理を選んだ場合は録音を選択した提供者へ送信します。

音楽フォルダーは明示的に選んだ範囲だけを読み取り、元ファイルを書き換えません。声クローン素材は権利者の許可を得たものだけを使用してください。未復旧・未提供機能について、これらの説明は現在の提供を保証するものではありません。

### 開発者への送信

広告、アクセス解析、追跡、会話・エラーログの自動送信は行いません。問い合わせ時に利用者が送った情報は対応に必要な範囲で取り扱います。APIキー、会話全文、個人情報を添付しないでください。

### 削除

会話等はアプリ内で削除できます。アンインストールだけではローカルデータを自動削除しません。完全削除はアプリを終了した後、保存フォルダーと自分で作ったバックアップ・書き出しを確認して削除してください。APIキーの失効は各提供者の管理画面で行ってください。
