# 検証・第三者レビューの確認項目

Desktop α版の公開前に確認する項目です。第三者レビューはまだ実施していません。紹介ページの公開は、アプリ本体の配布開始を意味しません。

- 新規Windowsユーザー、Ollama未導入、モデルなし、APIのみ、オフラインでのセットアップ
- 既存会話・プロンプト・キーの保全、旧形式の履歴の追加読み込み
- モデル取得の実転送、完全終了後の継続、停止・再試行、通信断・容量不足
- 外部歌詞の実曲照合、ローカル優先、送信情報・提供者の利用条件
- UIのライト/ダーク、高DPI、キーボード、アクセシビリティ、長い表示
- APIキーの非表示・暗号化、外部通信の範囲、隔離コード実行の制限
- 公開する最終パッケージのウイルス検査、私的ファイルの混入検査
- 依存物・音源・画像のライセンス、署名、別PC検証、更新経路

機能ごとの状態は[ALPHA_FEATURES.md](ALPHA_FEATURES.md)、全体の配布準備は[RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md)を参照してください。
