# 権限と外部通信 (Desktop α版)

開発者: くなまお / kunamaokunamao052867@gmail.com

管理者権限での常用は不要です。PC全体への無制限なアクセスを許可する必要はありません。

| 項目 | 用途・範囲 | 拒否・未設定時 |
| --- | --- | --- |
| ファイル・フォルダー | 利用者が選択した添付、音楽、出力先。アプリ自身のデータはLocalAppDataに保存 | 対象の読込・出力のみ使えません |
| Ollama接続 | 設定したOllamaへ会話を送信。ローカルモデルはオフライン対応 | ローカルAIを利用できません |
| OpenRouter | API応答のため選択した会話・指示・添付を送信。モデル提供者にも処理されます | API AIを利用できません |
| Web検索・天気・URL | 短い検索語、指定URL、場所を外部サービスへ送信 | ネットワーク機能を利用できません |
| マイク・カメラ | 対応機能を利用するときにWindowsの許可が必要。診断では取得しません | 対応機能のみ利用不可。音声通話は現在開発中です |
| 位置情報 | 利用者の操作で取得・共有。天気等に利用すると指定場所を外部送信 | 手入力の場所で利用してください |
| 常駐 | 設定が有効な場合、チャットウィンドウを閉じても処理継続 | 通知領域メニューから完全終了できます |
| 追加ツール | 利用者が選んだ実行ファイルの検出。検出だけでは機能復旧を意味しません | 対応する追加機能のみ利用不可 |
| モデル取得 | 明示選択・容量確認後、Ollama公式レジストリから取得。画面とは別プロセスで完全終了後も継続 | 候補は表示できますが、新しいモデルを利用できません |
| 外部歌詞 | 標準は無料LRCLIB、lyrics.ovhまたはローカルのみを選択可能。曲名・アーティスト・アルバム・長さを照合に使用 | ローカルLRC・TXT・埋め込み歌詞のみ利用できます |

初回セットアップでは総RAM・空きRAM・CPU名/コア・GPU名/ドライバー・Windows/アーキテクチャ・保存先空き容量・Ollamaの接続時間/バージョン/モデル一覧・追加ツールの実行可否を調べます。GPUのVRAM/実割当や生成速度は未測定です。ハードウェアはローカルの固定Windows照会を使い、診断情報を開発者へ送りません。モデル保存先はOLLAMA_MODELS設定または標準パスから推定するため、Ollamaの起動時設定が異なると一致しません。

診断ではマイク、カメラ、位置情報、私的なファイル内容を読み取りません。APIキーを外部送信して試すこともしません。有効性・残高は実際の送信時に確認されます。

ダウンロードはアプリを完全終了しても続きます。停止は再度開いたセットアップ/設定画面で行えます。電源断・スリープ・Ollama停止時は継続できず、再試行が必要な場合があります。Ollamaが保存したモデルはアプリの削除では消えません。

APIキーはWindowsユーザー単位のDPAPIで保存し、通常画面では表示しません。会話DBは暗号化されていないため、共有PCではWindowsアカウントの保護も必要です。

アナリティクス、広告、開発者への自動ログ送信はありません。コード実行は同梱WebAssemblyの隔離環境で行い、通常のPC上のPythonを直接実行する仕組みではありません。

配信式自動更新は計画済みですが、このα版では未実装です。勝手なインストールやモデルダウンロードは行いません。

詳細は[プライバシーポリシー](PRIVACY_POLICY.md)をご確認ください。
