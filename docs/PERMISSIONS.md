# 権限と外部通信 (Desktop α版)

## プレイヤーのメディア取得・ブラウザー（未公開）

- プレイヤーAIへの送信は質問したときだけ。選択範囲から最大32フレームを抽出し、時刻付き8シート以内・題名・再生位置・抽出点付近の字幕を選択AIへ送ります。画像入力に対応するモデルのみ使用でき、動画/音声本体は送信しません。抽出専用の一時デコーダーを使うため、視聴中の再生位置は変えません。中止するとデコーダーと処理を解放します。画像はメモリー上だけに置き、前の質問の画像を再送しません。
- 動画は利用者のファイル選択・取得結果を開く操作・プレイヤーを開く操作の後に自動再生します。アプリを起動しただけでは勝手に再生しません。Musicの自動再生設定や音量とは連動しません。

- 単体ファイルはWindowsの選択画面で選んだ音源・動画だけを登録します。フォルダーの設定は残し、フォルダーを選び直すと戻せます。
- メディア取得は利用者がURLと取得権限を確認した場合だけ開始します。自分で導入したyt-dlp/ffmpegを使用し、同梱・自動更新しません。設定の実行環境で指定できます。
- 本体のCookie・キー・会話は渡しません。初期URLは公開HTTPS・標準ポートに限定し、内部IPや秘密情報を拒否します。外部ツールは利用者権限で動き、OSサンドボックスや全接続先のネットワーク隔離はありません。信頼する配信元のみ使用してください。
- 実行時はKEY/TOKEN/SECRET/PASSWORD/CREDENTIAL/COOKIE/AUTH等を名前に含む環境変数を除き、プロキシの自動利用も無効にします。URLの既知の認証パラメーターはエンコードを解いて確認します。あらゆる秘密情報を自動判定できるわけではないため、URL自体も確認してください。
- 最長15分、単品取得、ツール側2GB制限と保存先合計3GBの監視（1秒間隔、結合中の一時ファイルを含む）。厳密なディスククォータではなく瞬間的な超過はあり得ます。本体終了・停止でプロセスツリーを中断します。途中ファイルは残ります。
- メディアブラウザーは別プロファイル・空ページで開始し、音声はミュート。表示先へ普通のWeb通信を行います。本体へのブリッジ・ファイルマッピング・端末権限・直接ダウンロードは提供しません。現在URLの受け渡しだけ可能です。サイトの規約とコンテンツの権利に従って使用してください。

管理者権限での常用は不要です。PC全体への無制限なアクセスを許可する必要はありません。

## ショートカット

プレイヤー・Mini Dock・常駐音声入力の追加キーは既定でオフです。有効にした組み合わせだけWindowsに登録し、ほかのアプリのキー入力全体を記録しません。キーが競合した場合は元の設定を維持します。常駐音声入力のキーを押すとマイクで認識し、その文章を選択した会話AIへ送ります。Windowsのマイク設定と既存の画面アクセス設定は変更しません。音声入力のキーを有効にしただけで録音は始まりません。

## 機能ごとの範囲

| 項目 | 用途・範囲 | 拒否・未設定時 |
| --- | --- | --- |
| ファイル・フォルダー | 利用者が選択した添付、音楽、出力先。アプリ自身のデータはLocalAppDataに保存。音楽ファイルのタグを書き換えるのは、アーティスト名の補完で確認したときだけ（元に戻せます） | 対象の読込・出力のみ使えません |
| コーディング | 利用者が開いたフォルダーの中だけで、AIがファイルを読み書きし、コマンド・開発サーバーを実行。書き込み・削除・コマンドはモードに応じて確認（フルアクセスはフォルダー内の操作を確認なしで実行）。秘密情報らしいファイルは毎回確認。変更前のファイルは元に戻すためLocalAppDataに保存 | コーディングモードのみ使えません |
| ブラウザーパネル | コーディングの動作確認用。アプリ本体とは別のプロファイルで表示したサイトへ直接接続。localhost以外を開く・操作する前は確認。ダウンロード・カメラ・マイク等の許可は行わない | パネルのみ使えません |
| Ollama接続 | 設定したOllamaへ会話を送信。ローカルモデルはオフライン対応。Ollamaが導入済みで止まっている場合は、アプリ起動時にOllama本体（トレイアプリ）を起動 | ローカルAIを利用できません |
| 外部AI（OpenRouter・OpenAI・Anthropic・Gemini・ChatGPT） | 応答のため選択した会話・指示・添付（コーディングではAIが読んだファイル内容・コマンド出力）を送信。モデル提供者にも処理されます | 外部AIを利用できません |
| ローカルAIサーバー | 登録したこのPCまたは家庭・社内ネットワークのアドレスだけに接続（llama.cpp・LM Studio・Jan等）。「このPCで探す」は127.0.0.1の決まったポートのみ確認 | 該当のローカルAIを利用できません |
| Web検索・天気・URL | 検索語は設定したSearXNGへ（DuckDuckGoは設定で有効にした場合のみ）、天気は地域名か約1kmに丸めた座標をOpen-Meteoへ送信。URLは指定サイトへ直接接続し、読めない場合はURLをCommon Crawlへ送って保存コピーを探す | ネットワーク機能を利用できません |
| カメラ | キャラクター機能の写真撮影など、利用者が操作したときだけ使用。Windowsのカメラ許可が必要 | 写真撮影のみ利用不可 |
| 位置情報 | 利用者の操作で、Windowsの位置情報から取得・共有。天気等に利用すると約1kmに丸めた座標を外部送信 | 手入力の場所で利用してください |
| 常駐 | 設定が有効な場合、チャットウィンドウを閉じても処理継続 | 通知領域メニューから完全終了できます |
| マイク | 音声入力・音声メモの操作時に使用。呼びかけをオンにした場合は待機中も使用。Windowsのマイク許可が必要（音声通話は開発中） | 音声関連の機能のみ利用不可 |
| ローカル音声エンジン | 読み上げ文をこのPCのVOICEVOXへ、Whisper認識を選んだ場合の録音をこのPCのwhisper.cpp serverへ渡します（数字のループバックIPのみ）。クラウドに自動切り替えしません。実行ファイルの選択・起動は利用者の操作時だけ | 設定「アシスタント・声」で読み上げをオフ、認識をWindowsへ戻せます。エンジン・音源・モデルの自動導入はありません |
| 選んだ文字 | Mini Chat の「選んだ文字を Mini Chat で使う」のキー（既定 Ctrl+Alt+Q）を押したときだけ、前面のアプリで選んでいる文字を読み取り（読めないアプリではコピーしてクリップボードを元に戻す）、ボタンや質問で送るまでAIに送らない。Privacy Zone のアプリとパスワードの欄は読まない | 設定の「Mini Chat」でオフ。キーを押さない限り何も読まない |
| 呼びかけ（常駐アシスタント） | 「ココロネと呼んで使う」をオンにしたときだけ、マイクで呼びかけの言葉をこのPCの中で聞き取る（音声は保存・送信しない）。呼ばれたあとの質問は文字にしてから選んだAIへ送る | 既定はオフ。設定の「Mini Chat と常駐」でオフ。オフの間はマイクを使わない |
| 追加ツール | 設定で選んだ実行ファイル、またはPATH上のffmpeg・ffprobe・yt-dlp・pythonを、バージョン確認の固定引数でのみ起動して検出（Microsoft Storeの代替プログラムは対象外） | 対応する追加機能のみ利用不可 |
| モデル取得 | 明示選択・容量確認後、Ollama公式レジストリから取得。画面とは別プロセスで完全終了後も継続 | 候補は表示できますが、新しいモデルを利用できません |
| 外部歌詞 | 標準は無料LRCLIB、lyrics.ovhまたはローカルのみを選択可能。曲名・アーティスト・アルバム・長さを照合に使用 | ローカルLRC・TXT・埋め込み歌詞のみ利用できます |

初回セットアップでは総RAM・空きRAM・CPU名/コア・GPU名/ドライバー・Windows/アーキテクチャ・保存先空き容量・Ollamaの接続時間/バージョン/モデル一覧・追加ツールの実行可否を調べます。GPUのVRAM/実割当や生成速度は未測定です。ハードウェアはWindowsのレジストリとシステム情報から直接読み取り（補助プログラムやスクリプトは起動しません）、診断情報を開発者へ送りません。モデル保存先はOLLAMA_MODELS設定または標準パスから推定するため、Ollamaの起動時設定が異なると一致しません。

診断ではマイク、カメラ、位置情報、私的なファイル内容を読み取りません。APIキーを外部送信して試すこともしません。有効性・残高は実際の送信時に確認されます。

ダウンロードはアプリを完全終了しても続きます。停止は再度開いたセットアップ/設定画面で行えます。電源断・スリープ・Ollama停止時は継続できず、再試行が必要な場合があります。Ollamaが保存したモデルはアプリの削除では消えません。

APIキーはWindowsユーザー単位のDPAPIで保存し、通常画面では表示しません。会話DBは暗号化されていないため、共有PCではWindowsアカウントの保護も必要です。

アナリティクス、広告、開発者への自動ログ送信はありません。チャットのコード実行は同梱WebAssemblyの隔離環境で行います。コーディングモードでは、利用者が開いたフォルダーで、承認（またはフルアクセス）のもとPC上のPython・Node.js等を実際に実行します。

配信式自動更新は計画済みですが、このα版では未実装です。勝手なインストールやモデルダウンロードは行いません。

詳細は[プライバシーポリシー](PRIVACY_POLICY.md)をご確認ください。
