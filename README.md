# ココロネAI for Desktop

**頼んだことを、最後までやってくれる。** Windows 11向けのAIアシスタント（無料）

このPCで動くローカルAI（Ollama）だけでも使えます。必要なときは外部のAI（OpenRouter・OpenAI・Anthropic・Gemini など）にも切り替えられます。

## v1.0.0（正式版）の新しいこと

- **ワーク：なんでも頼めるAIエージェント** — 資料・表・スライドづくり、出典つきの調べもの、知らない作業も自分で調べて最後まで。画面を閉じても裏で進みます。料金の目安と上限、依頼の範囲かを別のAIが確かめる見張り役、行動の記録つき
- **AIがPCとブラウザーを使う** — AI専用のブラウザー、画面の操作、ファイルの整理など。ログイン情報はAIに見せず、買い物は毎回確認してから
- **自分だけのエージェントとメモリー** — 名前・姿・話し方を決めたエージェントを何人でも。声でも頼めます。一度話したことも覚え、「忘れて」で消せます
- **コネクター** — メール・カレンダー・GitHub・Notion・LINE・MCP などをつなぎ、アプリごとにどこまで任せるかを選べます
- **スマホから** — Cloudflare Tunnel（Cloudflare Access の本人確認つき）でつなぎます
- **作る・比べる** — 動画の作成、このPCで動く画像・動画生成AI、画像スタジオ、2つのAIを並べるモデル比較
- **Music と歌詞の演出** — 曲の終わりとテンポで切り替える AutoDJ、より正確な流れる歌詞。「演出をAIで作る」を押した曲は、AIが歌詞の意味を読んで言葉ごとに動かします（ベータ）

## できること

### ワーク：頼んだことを最後まで

資料・表・スライドづくり、出典つきの調べもの、計算や集計など、頼んだ作業をAIが道具を組み合わせて最後まで進めます。画面を閉じても裏で続き、終わったら通知します。危ない操作の前には確認し、料金の目安と上限も表示します。

<img src="assets/readme/work.png" alt="ワークの画面。何を任せますか？と、表にまとめる・調べてレポートなどの提案" width="720">

### 歌詞の意味どおりに動く演出（ベータ）

「演出をAIで作る」を押すと、AIが歌詞の意味を読んで、言葉ごとに合う動きを付けます。「夜明け」は昇り、「降る」は落ち、「飛び込もう」は飛び込みます。押した曲だけを解析し、もう一度押すと止まります。

<img src="assets/readme/lyric-effects.gif" alt="フルスクリーンプレイヤーで、歌詞の言葉が意味に合わせて昇ったり落ちたりする" width="600">

<sub>デモ用に作った曲と歌詞です。</sub>

### 自分だけのエージェント

名前・姿・話し方・呼び名を決めて、自分だけのエージェントを何人でも作れます。声でも頼めて、役割を決めるとチームとして働きます。

<img src="assets/readme/agents.png" alt="設定の自分だけのエージェント。名前・姿・話し方を選ぶ" width="720">

### コネクター

メール・カレンダー・GitHub・Notion・LINE・MCP などをつなぐと、チャットとワークのAIが使えるようになります。アプリごとに、AIがどこまでしてよいかを選べます。パスワードやトークンはAIに渡しません。

<img src="assets/readme/connectors.png" alt="コネクターの画面。メール・カレンダー・GitHubなどのつなぐボタン" width="720">

### 歌声に合わせて流れる歌詞

フルスクリーンプレイヤーでは、左にジャケット、右に歌詞を大きく表示します。歌詞は歌声に合わせて左から右へなめらかに色が付き、背景はジャケットの色から作ったグラデーションが、バスドラムとベースに合わせてゆっくり動きます。単語ごとの時刻が無い歌詞も、PCの中のAIで歌声に位置を合わせて作れます。

<img src="assets/readme/music-fullscreen.gif" alt="フルスクリーンプレイヤーで、歌声に合わせて歌詞が左から右へ色づいていく" width="720">

### カラオケと歌詞の日本語訳

ボーカル消去・キー変更（±12半音）・速さ（0.5〜1.5倍）を、その場で切り替えられます。英語の歌詞には、AIが意味を優先した日本語訳を1行ずつ添えます。

<img src="assets/readme/karaoke.png" alt="英語の歌詞と日本語訳、カラオケのボーカル消去・キー・速さの設定" width="720">

<img src="assets/readme/music.png" alt="ミュージック画面。曲の一覧と、右に再生中の曲と流れる歌詞" width="720">

### チャットで、AIが道具を出す

通常のチャットでも、AIが必要に応じてWeb検索・ページの読み取り・動画の解析・道具を自分で使い、途中経過を見せながら答えます。QRコード・単位変換・色・タイマーなどは、答えの下にその場で使える道具として出てきます。

<img src="assets/readme/chat-tool.png" alt="チャットでQRコードを頼むと、答えの下にQRコードの道具が出る" width="720">

### 17の道具

メモ・ToDo・単位変換・日付計算・世界時計・ポモドーロ・環境音・QRコード・色・字幕の変換など。右側のAIが、開いている道具の中身を見て手伝います。自動実行やMCP（外部ツール）もここから設定します。

<img src="assets/readme/toolbox.png" alt="道具パネル。検索と、グループ別の道具のカード" width="720">

### AIが、回答の中に画面を作る（Intelligent UI）

「旅行の予算を、動かして試せる画面にして」のように頼むと、スライダーや計算、グラフ・年表のある画面が回答の中に出てきます。AIが書くのは画面の設計図だけで、プログラムは実行しません。作った画面は画像（PNG・SVG）で保存できます。

<img src="assets/readme/intelligent-ui.gif" alt="旅行の予算をスライダーで動かすと合計が変わる画面" width="560">

### 答えを確かめやすく

Web検索の答えには、使ったサイトと記事の日付、根拠になった文章が出ます。回答はその場で編集して差分を確認でき、別のモデルでやり直して見比べることもできます。

<img src="assets/readme/evidence.gif" alt="Web検索の答えと、根拠のサイトと文章の表示" width="580">

### 話している人ごとに文字にする（音声メモ）

録音や音声ファイルを、話している人ごとに分けて文字にします。処理はすべてこのPCの中です。話者の推定が違っていたら、押して直せます。

<img src="assets/readme/voice-memo.gif" alt="音声ファイルを取り込むと、話者ごとに分けた文字起こしが表示される" width="640">

### どこからでも呼べる（Mini Chat・Mini Dock）

`Ctrl+Shift+Space` で、どの画面の上からでも小さなチャットを呼べます。キーを押したまま話しかけることもできます。Mini Dock には音楽・タイマー・電卓・PCの状態（CPU・メモリ・GPU・電池）が入っています。

<img src="assets/readme/mini-chat.gif" alt="小さなチャットで質問し、回答の中に画面ができる" width="400">

### うまくいかないときも、次の一手がわかる

失敗したときは、理由と次にやることがその場に出ます。ボタン1つでやり直せて、設定が足りなければ直すボタンも出ます。

<img src="assets/readme/recovery.gif" alt="検索に失敗したときの案内と、やり直しのボタン" width="580">

### ほかにも

- Word・Excel・PowerPoint・PDF を、AIに送る前にプレビュー
- コマンドパレット（`Ctrl+K`）で、機能やPCのアプリを名前で呼び出し
- プロジェクトの記憶、システムプロンプト、メモリー、会話の書き出し
- コーディングモード（AIが作業し、操作はあなたが許可。元に戻すことも可能）
- ミュージック（歌詞・カラオケ・フルスクリーン）、ココロネプレイヤー（音楽と動画）、天気、URLの読み取り、通知領域への常駐、ライト / ダーク（Windowsに合わせる）
- 道具パネル、自動実行、MCP（外部ツール）、常駐アシスタント、VOICEVOX の読み上げ

モデル・接続先・PCによって、使える機能や品質は変わります。詳しくは[機能の状態](docs/ALPHA_FEATURES.md)をご覧ください。

## 大切にしていること

1. **操作の一貫性** — 同じ見た目のものは、どこでも同じように動く
2. **状況がわかる画面** — 今なにが起きているか、待てばよいのかがわかる
3. **設定しなくても使える** — 最初から使いやすい状態で始まる
4. **自然な失敗と復旧** — うまくいかないときは、理由と次の一手を
5. **機能が増えても画面は複雑にしない**

## 対応環境

- Windows 11 x64
- Microsoft Edge WebView2 Runtime（Windows 11は標準搭載）。インストーラー版とZIPは .NET を同梱
- ローカルAIを使う場合: [Ollama](https://ollama.com/download/windows) などのローカルAIとモデル
- 外部AIを使う場合: 各サービスのAPIキー（またはChatGPTのアカウント）。**利用料金はご自身のアカウントに発生します**
- 音声メモと話しかける機能: Windowsの日本語の音声認識
- カラオケのボーカル分離・AIで作る流れる歌詞（任意）: Python に demucs、さらに whisperx と faster-whisper（同梱・自動ダウンロードはしません）

AIモデルとAPIキーは同梱していません。

## はじめかた

1. [Releases](https://github.com/Naokuma005288/KokoroNe-AI/releases/latest) から `.msi`（おすすめ・管理者権限は不要）か `.zip` をダウンロードします
2. ハッシュ値と署名者を確かめてから開きます（初回のSmartScreenは「詳細情報」→「実行」）
3. 初回セットアップで、ローカルAI・外部AI・両方のどれを使うかを選びます。PCの診断で、入っているモデルやおすすめの候補がわかります
4. 前の版をお使いの方は、新しい `.msi` を開くとそのまま更新できます（会話・設定は引き継がれます）

## データとプライバシー

- 会話・設定などはこのPCの `%LOCALAPPDATA%\LumaAI-Desktop` に保存します（旧名称のフォルダー名です）。APIキーはWindowsのDPAPIで保護します
- 外部AIを使うと、回答に必要な会話や選んだ添付がそのサービスへ送られます。ローカルAIだけなら、会話はPCの外へ出ません（Web検索・天気・URLの読み取りなどを使うと、検索語やURLはその接続先へ送られます）
- 音声メモの音声と文字は、PCの外へ送りません
- 広告・アクセス解析・開発者への会話やログの自動送信はありません
- 送り先と費用は、アプリの「プライバシーと費用」の画面でまとめて確かめられます
